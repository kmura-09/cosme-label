表示名称は成分表に載せる日本語名。空なら INCI 名で表示します。構成比は原料 100 g 中の質量%。ブレンド原料 (界面活性剤水溶液など) は活性分と水を分けて登録すると、成分表で水が正しく合算されます。不開示成分がある場合は合計 100% 未満でも保存できますが、不足分は成分表に載りません。

成分マスタ (INCI ↔ 表示名称)

成分マスタが空です。 成分表を日本語の表示名称で出すには、INCI 名と表示名称の対応が必要です。よく使う基本成分 300 件を読み込むか、お手元の成分表示名称リスト (工業会の一覧など。「INCI名」「表示名称」の列があればそのまま読めます) を CSV で読み込んでください。表示名称が無くても INCI 名で成分表は作れます。

初回アクセス時に、市販原料でよく使われる基本成分 300 件 (水、BG、グリセリン、フェノキシエタノール…) が自動で入ります。自分で育てる INCI 辞書。ここに登録した表示名称は、原料登録で INCI を入れたときに自動で入り、成分表の表示名称の既定値になります (原料側で個別に入れた表示名称があればそちらを優先)。原料を保存すると、その構成成分は自動でここにも追加されます。

成分の登録

配合目的と由来は「訴求点の候補」(〇〇（保湿剤）配合、植物由来成分 N 種配合) に使います。天然由来率は ISO 16128 の考え方で、水・植物・鉱物は 100、石油・シリコーン・合成ポリマーは 0、植物油脂から作った誘導体は原料メーカーの値を入れてください。処方の自然由来指数はここから配合% 加重で計算します。

使い方

    
    
      
  1. 成分登録に INCI 名と表示名称 (日本語) の対応を登録します。初回は基本成分 300 件が自動で入り、お手元の成分表示名称リストの CSV を読み込めば増やせます。原料を保存すると構成成分は自動でここにも入るので、後からまとめて表示名称を付けることもできます。
    2. 
      
  2. 原料登録で、使う原料 (商品名) と、その原料 100 g 中の各 INCI の質量% を登録します。INCI を入れると成分マスタの表示名称が自動で入ります。まず「サンプル原料を読込」で 33 件の例を入れて試せます。
    3. 
      
  3. 成分表生成で、原料と配合% を並べます。「処方をコピペで入力」に 1 行 1 原料で貼り付けるのが速いです。
    4. 
      
  4. 右に全成分表示の記載順が出ます。日本語 / INCI の 1 行テキストはボタンでコピーできます。
    5. 
    

    
記載順の規則

    
    
      
  • 配合量の多い順 (質量% 降順)。同じ INCI が複数原料から来る場合は合算します。
    • 
      
  • 1% 以下の成分は順不同で記載できます (本表は降順のまま「順不同可」と表示)。閾値は変更できます。
    • 
      
  • 着色剤は配合量に関わらず末尾にまとめられます。原料登録の「着色剤」チェック、または CI 番号表記 (CI 77891 など) が対象です。
    • 
    

    
規制チェック

    
EU 1223/2009 Annex、化粧品基準 (厚生労働省告示第331号)、KFDA、21 CFR 352 由来の配合上限・配合禁止 (595 行) と突き合わせます。剤型や地域を指定しない場合は最も緩い上限を採用します (真値を切り落とさない保守側)。規制は改正されます。最新の規制原文を必ず確認してください。

    
訴求点の候補

    
成分表と成分辞書 (配合目的・由来・天然由来率) から、根拠のある訴求の候補を並べます。「〇〇（保湿剤）配合」型の配合成分訴求、「植物由来成分 N 種配合」型の由来訴求、ISO 16128 の考え方による自然由来指数 (水を含む / 除く、未登録成分がある場合はその幅)、および表示できるフリー表示です。候補は成分辞書の登録内容に依存するので、辞書を整えるほど充実します。文言の採用可否 (薬機法の効能効果の範囲、景品表示法) は利用者の判断です。

    
訴求文を LLM で作る

    
成分表・成分ごとの配合目的と由来・訴求候補・自然由来指数・使えるフリー表示を「事実」としてまとめ、製品名やターゲットと一緒に LLM に渡して商品説明の下書きを作ります。「化粧品」モードでは効能効果の 56 項目の範囲に収め、成分の効果を断定せず配合目的で表現するよう指示します。事実にない成分や数値を作らないことも指示に含めていますが、生成文は下書きです。必ず人が確認してください。

    
配合% と原料の商品名はプロンプトに含めません。外部の LLM に渡すのは、全成分表示 (公開情報)、成分辞書の配合目的・由来、候補文、自然由来指数だけです。無料の対話サービスは入力を学習に使う場合があるので、処方の機密が混ざらない設計にしてあります。送る前に「プロンプトを表示」で中身を確認できます。

    
API キーは扱いません。「プロンプトをコピー」して手持ちの ChatGPT・Claude・Gemini などに貼るか、「ChatGPT で開く」「Claude で開く」でプロンプト入りの新しいチャットを開きます (URL に載せる都合で短縮版)。Gemini はプロンプト入りの URL を受け付けないため、「Gemini で開く」はプロンプトをコピーしてから Gemini を開くので、入力欄に貼り付けてください。

    
フリー表示チェック

    
パラベンフリー、フェノキシエタノールフリー、防腐剤フリー、旧表示指定成分フリー (昭和55年厚生省告示の 102 成分 + 香料)、無香料、無着色、タール色素フリー、アルコールフリー、鉱物油フリー、シリコンフリー、サルフェートフリー、PEG フリー、EDTA フリー、紫外線吸収剤フリー、紫外線散乱剤フリー、グルテンフリー、尿素フリーの 17 種について、成分表の INCI にルール (data/free_claims.json) を当てて「該当なし / 該当あり / 要確認」を出します。「要確認」は防腐補助剤や精油、酸化チタンのように定義や用途で扱いが変わる成分です。ルールは一般的な慣行に基づく目安で、表示の可否は各社基準・公正競争規約・景品表示法の観点で別途判断してください。「フリー表示ルール」タブで、表示のオン・オフ、該当・要確認・除外にする成分の追加、自分の表示の作成ができます (設定はブラウザに保存、JSON で社内共有可)。

扱わないこと

データの保存場所

    
すべてブラウザ内で処理され、原料データはこのブラウザの localStorage にだけ保存されます。サーバーには何も送りません。ブラウザのサイトデータを消すと原料も消えるので、JSON 書出でバックアップしてください。
